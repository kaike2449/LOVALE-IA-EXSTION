# Lovable AI Hub

Extensão Chrome/Chromium para organizar prompts antes de abrir o Lovable ou outra IA.

## Recursos
- Interface dark moderna.
- Chat/prompt com histórico local do último prompt.
- Seleção de arquivos e imagens.
- Melhorador de prompts sem API externa.
- Seleção de destino: Lovable, ChatGPT, Claude ou Gemini.
- Copia o prompt para a área de transferência e abre o serviço escolhido.
- Não usa chave de API própria e não implementa bypass de créditos, limites ou autenticação.

## Instalação no Chrome/Edge/Brave
1. Baixe ou clone este repositório.
2. Abra a página de extensões do navegador.
3. Ative o modo de desenvolvedor.
4. Escolha **Carregar sem compactação** e selecione a pasta do projeto.
5. Abra a extensão pelo ícone do navegador.

## Sobre créditos
A extensão não faz chamadas de API para gerar respostas. Ela prepara o conteúdo localmente, copia o prompt e abre o serviço escolhido. Qualquer consumo de créditos, limites ou recursos pagos do Lovable/IA continua sendo controlado pelo próprio serviço.
